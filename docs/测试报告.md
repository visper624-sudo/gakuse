## 四、缺陷与已知问题

| 级别 | 问题 | 处理 |
| --- | --- | --- |
| 低 | 扫描版 PDF 无文本层 | 明确报错「需接入 OCR 适配器」，解析器已预留 OCR 扩展位 |
| 低 | `.doc` 旧格式不支持 | 提示另存为 `.docx` |
| 低 | 本地哈希向量的聚类阈值（0.60）低于真实 Embedding 的经验值（0.88） | 页面与文档均标注阈值随引擎调整，可通过环境变量覆盖 |
| 提示 | 权限缓存为进程内缓存 | 单实例演示无影响；多实例需改用 Redis 广播失效 |
