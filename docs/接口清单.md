# 接口清单

> 所有接口以 `/api` 为前缀，返回统一结构：`{"code": 0, "data": {...}}`，异常返回 `{"code": 1, "message": "...", "error": "..."}`。
> 鉴权：`Authorization: Bearer <JWT>`（也支持 `?token=` 便于演示/截图）。功能权限不足返回 `403`，未登录返回 `401`。

## 1. 认证与组织

| 方法 | 路径 | 说明 | 权限 |
| --- | --- | --- | --- |
| POST | `/api/auth/login` | 账号密码登录，返回 JWT 与用户上下文（含角色、部门、菜单/操作权限） | 公开 |
| GET | `/api/auth/me` | 当前登录用户上下文 | 登录 |
| POST | `/api/auth/logout` | 退出并记录审计 | 登录 |
| GET | `/api/org/tree` | 部门树（含成员数、知识单元数） | 登录 |
| POST | `/api/org/depts` | 新增部门 | `org:manage` |
| PUT | `/api/org/depts/{id}` | 修改部门 | `org:manage` |
| DELETE | `/api/org/depts/{id}` | 删除部门（含成员/子部门校验） | `org:manage` |
| GET | `/api/org/users` | 用户列表（支持关键字、部门过滤） | 登录 |
| POST | `/api/org/users` | 新增账号（默认密码 123456） | `org:manage` |
| PUT | `/api/org/users/{id}` | 修改姓名/部门/岗位/角色/状态 | `org:manage` |
| POST | `/api/org/users/{id}/reset-password` | 重置密码 | `org:manage` |
| GET | `/api/org/roles` | 角色列表 + 权限目录 + 各角色权限 | 登录 |
| PUT | `/api/org/roles/{id}/perms` | 保存角色功能权限 | `org:manage` |

## 2. 知识维护

| 方法 | 路径 | 说明 | 权限 |
| --- | --- | --- | --- |
| GET | `/api/kb` | 台账分页查询（关键字、格式、分类、部门、权限类型） | `menu:kb` |
| GET | `/api/kb/filters` | 分类/格式/部门/角色/用户下拉数据 | `menu:kb` |
| GET | `/api/kb/{id}` | 知识单元详情（含权限配置与前 3 个切片） | `menu:kb` |
| GET | `/api/kb/{id}/chunks` | 切片分页列表（页码、段落、字符区间、标题路径） | `menu:kb` |
| PUT | `/api/kb/{id}` | 修改标题/分类 | `kb:update` |
| DELETE | `/api/kb/{id}` | 删除知识单元及其切片与权限 | `kb:delete` |
| PUT | `/api/kb/{id}/status` | 启用/停用 | `kb:delete` |
| PUT | `/api/kb/{id}/perms` | **四维权限配置**（global / departments / roles / users） | `kb:perm` |
| POST | `/api/kb/{id}/reparse` | 按最新参数重建索引 | `kb:update` |
| POST | `/api/ingest/upload` | multipart 批量上传（`files` + `category`），同步解析切片入库 | `kb:create` |
| GET | `/api/ingest/tasks` | 最近导入任务与进度 | 登录 |

## 3. AI 问答

| 方法 | 路径 | 说明 | 权限 |
| --- | --- | --- | --- |
| POST | `/api/chat/stream` | **SSE 流式问答**，事件：`ack / trace / denied / delta / citations / notice / done / end` | `ai:chat` |
| POST | `/api/chat/ask` | 同步问答（脚本与测试使用），返回答案、引用、轨迹 | `ai:chat` |
| GET | `/api/chat/sessions` | 历史会话列表 | 登录 |
| POST | `/api/chat/sessions` | 新建会话 | 登录 |
| GET | `/api/chat/sessions/{id}/messages` | 会话消息（含引用、鉴权轨迹、时延、token） | 登录 |
| DELETE | `/api/chat/sessions/{id}` | 删除会话 | 登录 |
| GET | `/api/chat/suggestions` | 推荐提问（含已发布 FAQ） | 登录 |

### SSE 事件示例

```
event: trace
data: {"type":"trace","trace":{"retrieved":20,"allowed_ku":[1,2,5],"denied_ku":[3,4],
        "allowed_count":14,"denied_count":3,"top1_sim":0.5,
        "candidates":[{"chunk_id":6,"ku_id":3,"title":"受限知识单元（标题已隐藏）","allowed":false}]}}

event: delta
data: {"type":"delta","text":"一线城市（北京、上海..."}

event: citations
data: {"type":"citations","items":[{"index":1,"ku_id":1,"title":"差旅报销标准","page_no":2,"para_index":1,...}]}
```

## 4. 沉淀与运营

| 方法 | 路径 | 说明 | 权限 |
| --- | --- | --- | --- |
| GET | `/api/faq/candidates` | 候选 FAQ（可按状态过滤） | `menu:faq` |
| POST | `/api/faq/mine` | 触发聚类挖掘（`days` / `threshold` / `min_freq`） | `faq:review` |
| PUT | `/api/faq/candidates/{id}` | 编辑标准问法与答案 | `faq:review` |
| POST | `/api/faq/candidates/{id}/publish` | 审核发布并写入 FAQ 缓存 | `faq:review` |
| POST | `/api/faq/candidates/{id}/reject` | 驳回候选 | `faq:review` |
| GET | `/api/faqs` | 已发布 FAQ 列表 | `menu:faq` |
| PUT | `/api/faqs/{id}` | 修改问答 / 开关缓存 | `faq:review` |
| DELETE | `/api/faqs/{id}` | 下线 FAQ | `faq:review` |
| GET | `/api/gaps` | 知识缺口清单（含频次、部门、最高相似度） | `menu:faq` |
| POST | `/api/gaps/{id}/task` | 缺口转建补充任务 | `gap:handle` |
| PUT | `/api/gaps/{id}` | 更新缺口状态（忽略/已解决） | `gap:handle` |
| GET | `/api/tasks` | 补充任务列表 | `menu:faq` |
| PUT | `/api/tasks/{id}` | 更新任务状态 | `gap:handle` |

## 5. 看板与系统

| 方法 | 路径 | 说明 | 权限 |
| --- | --- | --- | --- |
| GET | `/api/dashboard/overview` | 看板聚合（`days` 1–30）：KPI、趋势、榜单、格式分布 | 登录 |
| GET | `/api/system/audit` | 审计日志分页（含越权拦截 `ai.denied`） | `audit:view` |
| GET | `/api/system/config` | 模型配置（Key 掩码）、向量化配置、检索参数、知识规模、重建索引提示 | 登录 |
| PUT | `/api/system/config` | 保存模型/向量化配置（含 `embedding_base_url` / `embedding_api_key` / `embedding_dim`） | `sys:config` |
| POST | `/api/system/config/test` | 对话模型连通性测试 | `sys:config` |
| POST | `/api/system/config/test-embedding` | 向量服务连通性测试（返回维度与耗时） | `sys:config` |
| GET | `/api/system/health` | 健康检查（版本、知识规模、引擎模式） | 公开 |

## 6. 功能权限编码

| 分组 | 编码 | 说明 |
| --- | --- | --- |
| 菜单 | `menu:dashboard` `menu:chat` `menu:kb` `menu:faq` `menu:org` | 控制左侧菜单与页面访问 |
| 操作 | `kb:create` `kb:update` `kb:delete` `kb:perm` | 知识维护 |
| 操作 | `faq:review` `gap:handle` | 沉淀运营 |
| 操作 | `ai:chat` | 问答调用 |
| 操作 | `org:manage` `sys:config` `audit:view` | 组织与系统管理 |
